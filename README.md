# Loja Javaveira - Sistema PDV

Sistema de pagamentos desenvolvido em Java utilizando conceitos de Programacao Orientada a Objetos.

## Funcionalidades

- Login de funcionarios
- Cadastro de gerentes
- Cadastro de operadores de caixa
- Alteracao de funcionarios
- Listagem de funcionarios
- Abertura e fechamento de caixa
- Pagamentos via PIX
- Pagamentos via Boleto
- Pagamentos via Cartao de Debito
- Pagamentos via Cartao de Credito
- Pagamento a vista e parcelado
- Listagem de pagamentos
- Relatorio de vendas

## Perfis

### Gerente

O gerente pode:

- Cadastrar funcionarios
- Alterar funcionarios
- Listar funcionarios
- Gerar relatorio de vendas

### Operador de Caixa

O operador pode:

- Abrir o caixa
- Realizar pagamentos
- Fechar o caixa
- Listar pagamentos

Os pagamentos somente podem ser realizados quando o caixa estiver aberto.

## Como executar

O projeto foi desenvolvido em Java.

Para executar:

1. Abra o projeto no VS Code.
2. Abra a pasta do projeto.
3. Execute o arquivo Main.java.
4. Utilize o menu apresentado no terminal.
